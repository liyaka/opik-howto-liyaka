# openai-agents-insurance-claims

A claims intake desk where a triage agent hands off to specialists, traced with Opik.

Run it with `uv sync && uv run main.py`, then open the `openai-agents-insurance-claims` project in Opik.
Each claim conversation shows up as one thread under the Threads tab.

*built with Opik · inspired by Opik's examples and documentation*
